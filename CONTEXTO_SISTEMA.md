# Contexto de gpcenter-back

La fuente de verdad integral y transversal de GP Center se mantiene en [`../GP-CENTER-WEB/CONTEXTO_SISTEMA.md`](../GP-CENTER-WEB/CONTEXTO_SISTEMA.md). Incluye arquitectura, módulos, actores, flujos, reglas, datos, convenciones para módulos nuevos, inconsistencias y verificaciones de frontend y backend.

Este repositorio aporta la API Laravel 12/PHP 8.2, Sanctum, modelos Eloquent, migraciones/tablas/vistas/procedimiento, seeders, archivos e integración con GP Central. Sus instrucciones operativas locales están en `AGENTS.md` y sus hechos durables en `MEMORY.md`.

La guía obligatoria para crear, integrar, complementar o corregir una página o módulo está en [`../GP-CENTER-WEB/CREACION_DE_PAGINAS.md`](../GP-CENTER-WEB/CREACION_DE_PAGINAS.md).
